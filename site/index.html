ที่แสดงหลักฐาน ไม่ตัดสินแทนคน

aeterna-rongroi มองหาร่องรอยที่โปรโกงทิ้งไว้บนเครื่อง Windows และการตั้งค่าที่เปิดทางให้โกงได้ง่าย แล้วแสดงเป็นหลักฐานให้คนดู ใช้เช็คเครื่องตัวเอง หรือให้แอดมินดูระหว่างแชร์หน้าจอ (SS) โดยผู้เล่นยินยอม ไม่มีวันบอกว่าเครื่อง "สะอาด"

ดาวน์โหลด · รุ่น 0.6.0 คู่มือ SS ดูโค้ด

⚠️ ยังเป็นรุ่นทดลอง (pre-alpha) rule ส่วนใหญ่ยังไม่ได้ลองกับเครื่องจริงมากพอ อย่าแบนใครเพราะสิ่งที่โปรแกรมนี้แสดง และอย่าใช้ยืนยันว่าใครไม่ผิด

ต่างจากโปรแกรมเช็คโปรอื่นตรงไหน

  • ไม่ส่งข้อมูลออกไปไหน

    โค้ดของโปรแกรมไม่มีส่วนที่ต่อเน็ตเลย และ CI จะไม่ยอมให้ build ผ่านถ้ามีใครเพิ่มเข้ามา ไม่จับภาพหน้าจอ ไม่อ่านประวัติเว็บ ไม่มีการรีโมตเข้าเครื่อง

  • เปิดให้ทุกคนตรวจได้

    rule ทุกตัวและการตรวจทุกข้ออยู่บน GitHub ใครก็อ่านได้ว่าโปรแกรมมองหาอะไร และมีเรื่องปกติอะไรบ้างที่ทำให้เกิดผลแบบเดียวกัน

  • หลักฐาน ไม่ใช่คำตัดสิน

    ไม่ให้คะแนน ไม่บอกว่าผ่านหรือไม่ผ่าน คนเป็นคนตัดสิน โดยใช้รายงานเป็นหลักฐานประกอบชิ้นหนึ่ง

รุ่น 0.6.0 ตรวจอะไรบ้าง

ตรวจอะไรอธิบาย
ตัว FiveM เองไฟล์ของ FiveM เป็นของแท้ที่มีลายเซ็นไหม มีไฟล์เสริมอะไรอยู่ในโฟลเดอร์ และเล่นครั้งล่าสุดเมื่อไรเทียบกับเวลาที่โฟลเดอร์ถูกเขียนใหม่ทั้ง Legacy และ GTA V Enhanced
โปรแกรมที่เคยรันสิ่งที่ Windows จำได้ว่าเพิ่งเปิดอะไรไปPrefetch, BAM, PCA · ใช้เป็นข้อมูลประกอบ ไม่มี rule ตัดสินจากชื่อไฟล์
ร่องรอยการลบบันทึกlog ของ Windows ถูกล้าง หรือถูกตั้งค่าไม่ให้บันทึก
การป้องกันถูกปิดMicrosoft Defender ถูกปิด, Secure Boot, TPM, memory integrity และการตั้งค่าความปลอดภัยอื่นของ Windows
driver อันตรายdriver ที่มีช่องโหว่ซึ่งรู้กันอยู่แล้ว โปรโกงใช้ช่องโหว่นี้เจาะลึกเข้าไปใน Windows ได้เทียบกับรายชื่อ LOLDrivers 1,847 ตัว
ไฟล์ที่ถูกลบหรือเปลี่ยนชื่อในโฟลเดอร์ไฟล์เสริมของ FiveM
Windows ที่ถูกดัดแปลงWindows ที่ถูกตัดระบบป้องกันออกมาก่อน เช่น Atlas, ReviOSเจ้าของเครื่องมีสิทธิ์ใช้ Windows แบบไหนก็ได้ แถวนี้บอกแค่ว่าเป็นแบบไหน
การตั้งค่าอื่นๆโปรแกรมไม่มีลายเซ็นที่เปิดเองตอนเปิดเครื่อง และไฟล์ hosts ที่เปลี่ยนเส้นทางของ FiveM หรือ Rockstar
ย้อนดูได้ไกลแค่ไหนเพื่อไม่ให้ "ไม่เจอ" ถูกเข้าใจว่า "ไม่เคยเกิดขึ้น"

รายละเอียดทุก rule: คู่มืออ้างอิง rule

SS ผู้เล่นใน 5 ขั้น

  1. ให้ผู้เล่นโหลดเองจากหน้า Releases ส่งลิงก์ให้ อย่าส่งไฟล์ให้เอง
  2. เช็คว่าเป็นไฟล์ของจริงเปิด PowerShell ในโฟลเดอร์ที่โหลดมา แล้วรัน Get-FileHash .\aeterna-rongroi-*-windows-x64.exe เทียบกับไฟล์ SHA256SUMS ในหน้า release ถ้าไม่ตรงให้หยุด
  3. เปิดโหมด SSกด "ตรวจระหว่างแชร์หน้าจอ (โหมด SS)" แล้วผู้เล่นเป็นคนกดยินยอมเอง ผู้เล่นปฏิเสธได้ และถ้าปฏิเสธ โปรแกรมจะไม่อ่านอะไรเลย
  4. ดูหัวรายงานต้องขึ้นว่า build ทางการ ถ้าขึ้น UNOFFICIAL BUILD ผลใช้ไม่ได้
  5. อ่านผลทีละแถวและอ่านเรื่องปกติที่ทำให้เกิดผลแบบเดียวกันด้วย

ขั้นตอนเต็มและวิธีอ่านทุกแถว: คู่มือตรวจเครื่องระหว่างแชร์หน้าจอ
