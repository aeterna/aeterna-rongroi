## 2. กฎสำหรับ session อื่น (สั้น)

1. **สลับมุมมองระหว่าง Overview และ Detailed Report:**
   - หน้ารายงานใน `apps/desktop/src/views/Report.tsx` รองรับ 2 โหมด: `summary` (Overview) และ `detailed` (Technical)
   - ข้อมูลของ Technical Detailed Report ยังคงอยู่ครบถ้วนและอัปเดตตาม State เสมอ (ไม่สูญหายเมื่อสลับโหมด)
2. **การคงมาตรฐาน Invariants & Privacy (ADR 0002 & ADR 0045):**
   - ห้ามแสดงข้อความตัดสินว่าเครื่อง "สะอาด" (Never say clean)
   - การคัดลอกหรือส่งออกข้อมูล (AI Export / Clipboard) ต้องคงฟังก์ชัน Mask ข้อมูลระบุตัวตนของผู้ใช้ (User folder path และ SIDs)
3. **ห้ามใช้ Emojis ใน UI:**
   - ใช้ inline SVG vector icons ตามมาตรฐานองค์กร Aeterna เท่านั้น
4. **การรัน Quality Checks ก่อนส่งงาน:**
   - `cargo xtask check-locales` (ตรวจการแปล en และ th ให้ครบทั้งคู่)
   - `cargo xtask check-unicode`
   - `cargo xtask check-rules`
   - `cargo xtask check-versions`
   - `pnpm -C apps/desktop test` (Vitest)
