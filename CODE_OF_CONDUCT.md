# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, and keep discussion about the work. Harassment, personal
attacks and publishing other people's private information are not tolerated. That includes posting a
player's scan results or identity in public to shame them.

To report a problem, contact the maintainers listed in [GOVERNANCE.md](GOVERNANCE.md) through a private
channel (GitHub private vulnerability reporting is fine if nothing else is available). Reports are handled
confidentially.
