# aeterna-rongroi

> ⚠️ **ยังเป็นรุ่นทดลอง (pre-alpha)** ตอนนี้ตรวจได้แค่ไม่กี่อย่าง ยังไม่ควรใช้ตัดสินเรื่องจริง

**โปรแกรมตรวจเครื่อง (PC check) สำหรับชุมชน FiveM แบบ open-source ทำงาน offline** มองหาร่องรอยที่โปรโกง
ทิ้งไว้บนเครื่อง Windows และการตั้งค่าเครื่องที่เปิดทางให้โกงได้ง่าย แล้วแสดงหลักฐานให้ดู
**ไม่มีวันบอกว่าเครื่อง "สะอาด"**

Read in English: [README.md](README.md)

## คืออะไร — และไม่ใช่อะไร

| คือ | ไม่ใช่ |
|---|---|
| ตัวช่วยดูหลักฐาน ให้ผู้เล่นตรวจเครื่องตัวเอง หรือให้แอดมินดูโดยผู้เล่นยินยอม | หลักฐานว่าใครบริสุทธิ์หรือผิด |
| โปรแกรมระดับผู้ใช้ที่ **อ่านอย่างเดียว** | kernel driver, service หรืออะไรที่แอบรันเบื้องหลัง |
| เปิดเผย: rule และการตรวจทุกตัวอยู่ใน repo นี้ | มองเห็นโปรแบบฮาร์ดแวร์ (DMA) หรือเมนูที่ซ่อนจากการแชร์จอ |
| Offline: โค้ดของเราไม่ส่งอะไรออกไปไหน | บริการออนไลน์หรือรายชื่อแบน |

ผลทุกข้อเป็นอย่างใดอย่างหนึ่งใน 3 แบบ:

- **เจอ** — แสดงหลักฐานพร้อมบอกว่ามาจากไหน
- **ไม่เจอ** — บอกด้วยว่าแหล่งนั้นย้อนดูได้ไกลแค่ไหน (เช่น "log นี้เก็บแค่ไม่กี่วันล่าสุด")
- **ยังไม่ได้วัด** — พร้อมเหตุผล (เช่น "ต้องใช้สิทธิ์ผู้ดูแลระบบ")

## ความเป็นส่วนตัว

- **โค้ดของ aeterna-rongroi ไม่ส่งอะไรออก** CI จะไม่ยอมให้ build ผ่านถ้ามีคนเพิ่มโค้ด network
- **GUI ใช้ Microsoft WebView2** ซึ่งเป็นส่วนประกอบของ Windows อาจส่งข้อมูลวินิจฉัยตามการตั้งค่า Windows
  ของคุณ **รุ่น CLI ไม่ใช้ WebView2**
- ไม่ถ่ายภาพหน้าจอ ไม่อ่านประวัติเบราว์เซอร์ ไม่มีการควบคุมเครื่องจากระยะไกล
- **โหมด SS** (สำหรับแชร์หน้าจอ) ขอความยินยอมก่อน แสดงเฉพาะสิ่งที่ตรง rule และซ่อนชื่อผู้ใช้ใน path —
  **คุณปฏิเสธได้**

รายละเอียด: [PRIVACY.md](PRIVACY.md)

## ตรวจว่าไฟล์ที่โหลดมาเป็นของจริง

ตอนนี้ release ยังไม่ได้เซ็นโค้ด Windows SmartScreen จะขึ้นเตือนตอนเปิด ให้เปิด PowerShell ในโฟลเดอร์ที่โหลดมา:

```powershell
Get-FileHash .\aeterna-rongroi-*-windows-x64.exe
```

คำสั่งนี้แสดง hash ของไฟล์ aeterna-rongroi ทุกไฟล์ในโฟลเดอร์ ให้เทียบแต่ละค่ากับบรรทัดที่มีชื่อไฟล์เดียวกันใน `SHA256SUMS` ในหน้า release บน GitHub (ตัวพิมพ์เล็กหรือใหญ่ไม่มีผล) ไฟล์ของเวอร์ชันเก่าที่อยู่ในโฟลเดอร์เดียวกันจะไม่มีในรายการนั้น · build ที่ไม่ได้มาจากระบบ release ทางการ
จะขึ้นป้าย **UNOFFICIAL BUILD** ในหน้าต่าง ในหัว CLI และในทุกรายงาน ถ้าเห็นป้ายนี้หรือ hash ไม่ตรง
อย่าเชื่อผลตรวจนั้น

โปรแกรม offline ที่แสดงผลบนจอของผู้เล่นเอง พิสูจน์อะไรด้วยตัวเองไม่ได้ ระบบปฏิบัติการที่ถูกดัดแปลงอาจปลอม
สิ่งที่แสดงบนจอได้ ให้ถือผลเป็นหลักฐานประกอบให้คนตัดสิน

## สถานะ

| เฟส | ขอบเขต | สถานะ |
|---|---|---|
| M0 | repo, รูปแบบ rule, engine, ตรวจ Secure Boot, CLI และโครง GUI, ระบบ release | ออกใน 0.1.0 แล้ว |
| M1 | ตรวจโฟลเดอร์ FiveM, process ที่รันอยู่, สถานะเครื่องเพิ่มเติม, เปิดใหม่ด้วยสิทธิ์ admin | merge แล้ว แต่ยังไม่ได้ออกเป็นรุ่น |
| M2 | Prefetch, BAM, PCA, สัญญาณล้าง event log | parser ทั้งสี่ตัว merge แล้ว แต่ยังไม่มี collector ตัวไหนเรียกใช้ การสแกนจึงยังไม่แสดงอะไรจาก parser เหล่านี้ |
| M3 | รายชื่อ driver มีช่องโหว่, USN journal, Amcache, คู่มือ SS | วางแผนแล้ว |

"merge แล้ว" หมายถึงงานอยู่บน branch `dev` แต่ยังไม่ได้ออกเป็นรุ่น ตอนนี้มีรุ่นเดียวคือ 0.1.0 และระบบ release
ออกมาพร้อมรุ่นนั้น ([ADR 0008](docs/adr/0008-release-pipeline.md)) จึงอยู่ในแถว M0
