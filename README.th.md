# aeterna-rongroi

> ⚠️ **ยังเป็นรุ่นทดลอง (pre-alpha)** ตอนนี้ตรวจได้แค่ไม่กี่อย่าง ยังไม่ควรใช้ตัดสินเรื่องจริง

**โปรแกรมตรวจเครื่อง (PC check) สำหรับชุมชน FiveM แบบ open-source ทำงาน offline** มองหาร่องรอยที่โปรโกง
ทิ้งไว้บนเครื่อง Windows และการตั้งค่าเครื่องที่เปิดทางให้โกงได้ง่าย แล้วแสดงหลักฐานให้ดู
**ไม่มีวันบอกว่าเครื่อง "สะอาด"**

ใช้เป็น **โปรแกรมเช็คโปร FiveM** หรือ **สแกนเครื่อง** ก่อนเข้าเมือง (SS) ได้ ผู้เล่นเช็คเครื่องตัวเองได้
หรือให้แอดมินดูผ่านการแชร์หน้าจอ โดยผู้เล่นต้องยินยอม

Read in English: [README.md](README.md)

## คืออะไร — และไม่ใช่อะไร

| คือ | ไม่ใช่ |
|---|---|
| ตัวช่วยดูหลักฐาน ให้ผู้เล่นตรวจเครื่องตัวเอง หรือให้แอดมินดูโดยผู้เล่นยินยอม | หลักฐานว่าใครบริสุทธิ์หรือผิด |
| โปรแกรมระดับผู้ใช้ที่ **อ่านอย่างเดียว** | kernel driver, service หรืออะไรที่แอบรันเบื้องหลัง |
| เปิดเผย: rule และการตรวจทุกตัวอยู่ใน repo นี้ | มองเห็นโปรแบบฮาร์ดแวร์ (DMA) หรือเมนูที่ซ่อนจากการแชร์จอ |
| Offline: โค้ดของเราไม่ส่งอะไรออกไปไหน | บริการออนไลน์หรือรายชื่อแบน |

ผลทุกข้อเป็นอย่างใดอย่างหนึ่งใน 3 แบบ:

- **เจอ** — แสดงหลักฐานพร้อมบอกว่ามาจากไหน
- **ไม่เจอ** — บอกด้วยว่าแหล่งนั้นย้อนดูได้ไกลแค่ไหน (เช่น "log นี้เก็บแค่ไม่กี่วันล่าสุด")
- **ยังไม่ได้วัด** — พร้อมเหตุผล (เช่น "ต้องใช้สิทธิ์ผู้ดูแลระบบ")

## ความเป็นส่วนตัว

- **โค้ดของ aeterna-rongroi ไม่ส่งอะไรออก** CI จะไม่ยอมให้ build ผ่านถ้ามีคนเพิ่มโค้ด network
- **GUI ใช้ Microsoft WebView2** ซึ่งเป็นส่วนประกอบของ Windows อาจส่งข้อมูลวินิจฉัยตามการตั้งค่า Windows
  ของคุณ **รุ่น CLI ไม่ใช้ WebView2**
- ไม่ถ่ายภาพหน้าจอ ไม่อ่านประวัติเบราว์เซอร์ ไม่มีการควบคุมเครื่องจากระยะไกล และไม่อ่านว่าเครื่องเคยเชื่อมต่อไปที่ไหน
  ส่วนเครือข่ายอ่านแค่การตั้งค่าที่กำหนดว่า traffic ไปที่ไหน (ไฟล์ hosts, proxy, rule ของ firewall)
- โปรแกรมที่ Windows เริ่มเอง (service, `Run`, scheduled task) อ่านแค่ว่าแต่ละรายการเริ่มไฟล์ไหน
  ไม่อ่าน argument ที่โปรแกรมได้รับเลย ส่วน exclusion ของ Microsoft Defender อ่านโฟลเดอร์ โปรแกรม และชนิดไฟล์
  และนับแค่จำนวน address ของเครือข่าย
- **การสแกนแบบ Full อ่านมากกว่า และอ่านเฉพาะเมื่อคุณตอบตกลงก่อนเริ่มสแกน** ตอนนี้คือชื่อโฟลเดอร์ cache ของเซิร์ฟเวอร์ใน
  FiveM for GTA V Enhanced flag หรือสคริปต์ตอบแทนคุณไม่ได้ และในโหมด SS ชื่อเซิร์ฟเวอร์จะถูกซ่อนไว้ เว้นแต่คุณยินยอมให้แสดงแยกอีกข้อหนึ่ง
- **โหมด SS** (สำหรับแชร์หน้าจอ) ขอความยินยอมก่อน แสดงสิ่งที่ตรง rule, timeline ของเวลาที่หน้ายินยอมระบุไว้ และแต่ละแหล่งย้อนกลับไปได้ไกลแค่ไหน
  เทียบกับวันที่ส่วนต่าง ๆ ของเครื่องถูกติดตั้ง ([ADR 0061](docs/adr/0061-how-old-the-traces-are.md)) และซ่อนชื่อผู้ใช้ใน path —
  **คุณปฏิเสธได้**

รายละเอียด: [PRIVACY.md](PRIVACY.md)

## ตรวจว่าไฟล์ที่โหลดมาเป็นของจริง

ตอนนี้ release ยังไม่ได้เซ็นโค้ด Windows SmartScreen จะขึ้นเตือนตอนเปิด ให้เปิด PowerShell ในโฟลเดอร์ที่โหลดมา:

```powershell
Get-FileHash .\aeterna-rongroi-*-windows-x64.exe
```

คำสั่งนี้แสดง hash ของไฟล์ aeterna-rongroi ทุกไฟล์ในโฟลเดอร์ ให้เทียบแต่ละค่ากับบรรทัดที่มีชื่อไฟล์เดียวกันใน `SHA256SUMS` ในหน้า release บน GitHub (ตัวพิมพ์เล็กหรือใหญ่ไม่มีผล) ไฟล์ของเวอร์ชันเก่าที่อยู่ในโฟลเดอร์เดียวกันจะไม่มีในรายการนั้น · build ที่ไม่ได้มาจากระบบ release ทางการ
จะขึ้นป้าย **UNOFFICIAL BUILD** ในหน้าต่าง ในหัว CLI และในทุกรายงาน ถ้าเห็นป้ายนี้หรือ hash ไม่ตรง
อย่าเชื่อผลตรวจนั้น

โปรแกรม offline ที่แสดงผลบนจอของผู้เล่นเอง พิสูจน์อะไรด้วยตัวเองไม่ได้ ระบบปฏิบัติการที่ถูกดัดแปลงอาจปลอม
สิ่งที่แสดงบนจอได้ ให้ถือผลเป็นหลักฐานประกอบให้คนตัดสิน

## สถานะ

**รุ่นล่าสุด: [0.7.0](https://github.com/aeterna/aeterna-rongroi/releases/tag/v2026.10.03-0.7.0)** ออกวันที่ 3 ตุลาคม 2026 —
ยังเป็นรุ่นทดลอง (pre-release) มี rule 44 ตัว เกือบทั้งหมดยังเป็น `experimental` คือยังไม่ได้ลองกับเครื่องจริง
มากพอ อ่านผลทุกข้ออย่างระมัดระวัง · 0.7.0 เปลี่ยนหน้าตาของหน้าต่างเป็นธีมท้องฟ้าสว่าง การตรวจยังเหมือน 0.6.0
รุ่นก่อนหน้า: [CHANGELOG.md](CHANGELOG.md)

| ตรวจอะไร (ภาษาคน) | รายละเอียดทางเทคนิค |
|---|---|
| **ตัว FiveM เอง** — ไฟล์ของ FiveM เป็นของแท้ที่มีลายเซ็นไหม และมีไฟล์เสริมอะไรอยู่ในโฟลเดอร์ · **ตั้งแต่ 0.6.0:** เล่น FiveM ครั้งล่าสุดเมื่อไร เทียบกับเวลาที่โฟลเดอร์ถูกเขียนล่าสุด | ทั้ง Legacy และ GTA V Enhanced · ตรวจลายเซ็น Authenticode แบบ offline · โฟลเดอร์ `plugins` และ `asi` ของ Enhanced · โฟลเดอร์ cache ต่อเซิร์ฟของ Enhanced (เฉพาะ full scan และผู้เล่นยินยอม) · เซสชันล่าสุดของแต่ละ edition จากเวลาเริ่ม process, Prefetch และ BAM ([ADR 0062](docs/adr/0062-fivem-s-folders-beside-its-last-session.md)) |
| **โปรแกรมที่เคยรัน** — สิ่งที่ Windows จำได้ว่าเพิ่งเปิดอะไรไป | Prefetch, BAM, PCA, process ที่รันอยู่ · โหมดตรวจเครื่องตัวเองแสดงเป็นรายการ โหมด SS แสดงแค่จำนวน · ไม่มี rule ตัดสินจากสิ่งที่สามแหล่งนี้บันทึก เพราะระบุโปรแกรมได้แค่ด้วยชื่อไฟล์ ([ADR 0034](docs/adr/0034-prefetch-bam-and-pca-carry-no-identity.md)) |
| **ร่องรอยว่ามีการลบบันทึก** — log ของ Windows ถูกล้างหรือถูกปิดกั้น | event log ถูกล้าง · ไฟล์ event log หรือ Prefetch ถูกตั้งเป็นอ่านอย่างเดียว หรือไม่ใช่ไฟล์ที่ Windows เขียนลงไป |
| **การป้องกันถูกปิด** — แอนตี้ไวรัสและการตั้งค่าความปลอดภัยของ Windows | Microsoft Defender ถูกปิดการป้องกันแบบ real-time, service ถูกปิด, รายการยกเว้น (เฉพาะสิทธิ์ผู้ดูแลระบบ) · Secure Boot, TPM, memory integrity (HVCI), test signing, สวิตช์ป้องกัน exploit, การบันทึกของ PowerShell |
| **driver อันตราย** — driver ที่มีช่องโหว่ซึ่งรู้กันอยู่แล้ว โปรโกงใช้ช่องโหว่นี้เจาะลึกเข้าไปใน Windows ได้ | เทียบ SHA-256 ของ driver ที่ลงทะเบียนไว้กับ hash ของ [LOLDrivers](https://www.loldrivers.io/) ที่ยืนยันแล้ว 1,847 ตัว |
| **ไฟล์ที่ถูกลบหรือเปลี่ยนชื่อ** — ในโฟลเดอร์ไฟล์เสริมของ FiveM | NTFS change journal (USN) ของโฟลเดอร์ `plugins` และ `asi` พร้อมช่วงเวลาที่ journal ครอบคลุม |
| **Windows ที่ถูกดัดแปลง** — Windows ที่ถูกตัดระบบป้องกันออกมาก่อน | Atlas, ReviOS และแบบเดียวกัน จากร่องรอยการติดตั้งและสิ่งที่ Windows บอกเกี่ยวกับตัวเอง · service ที่ Windows แบบนี้มักปิด |
| **การตั้งค่าอื่นๆ** — โปรแกรมที่เปิดเองตอนเปิดเครื่อง และการเปลี่ยนเส้นทางเน็ต | โปรแกรมไม่มีลายเซ็นที่เริ่มเองและอยู่นอก Windows กับ Program Files · ชื่อของ FiveM หรือ Rockstar ในไฟล์ hosts |
| **ย้อนดูได้ไกลแค่ไหน** — เพื่อไม่ให้ "ไม่เจอ" ถูกเข้าใจว่า "ไม่เคยเกิดขึ้น" | เวลาเก่าสุดที่แต่ละแหล่งยังเก็บไว้ เทียบกับที่ปกติเก็บได้ |

ยังไม่มีแผนทำตอนนี้: Amcache ([ADR 0041](docs/adr/0041-amcache-feasibility.md))
